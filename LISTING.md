## Long description

```
HTML Export Viewer renders an HTML measure — typically a styled table built in DAX — and gives
report users one-click buttons to export it to PDF, Excel, or Word.

Unlike a plain "print the page" export, this visual preserves the actual on-screen formatting
(colors, bold, alignment, borders) in every export format, and can optionally produce an Excel
workbook with live, recalculating formulas instead of static numbers — useful for tables where
values are the result of a calculation (an escalation rate, a projection, a multi-year total)
that a user may want to adjust after export.

Key features:
- Export the same content to PDF, Excel (.xlsx), or Word
- Formatting-faithful exports — matches the colors, bold text, alignment, and borders shown on screen
- Optional live Excel formulas: mark specific cells with a formula template and a small set of
  named constants, and the Excel export writes real, recalculating formulas instead of baked-in values
- Configurable toolbar: show/hide, button position, button text, export file name
- No external services, no network access, no data collection — see the linked privacy policy

Setup requires a DAX measure that returns HTML content (a <table> at minimum) — see the linked
documentation for the exact format and a full example, including how to enable the live-formula
feature.
```
